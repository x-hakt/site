## The prose around it

The forced command is the whole trick. The key can only ever run the one program
the server pins to it, so a leaked key is a leaked ability to run that one
read-only report and nothing more. The `authorized_keys` line looks like this:

```
command="/usr/local/bin/report --json",no-port-forwarding,no-pty ssh-ed25519 AAAA...
```

Everything else in this note is filler until the real writing starts. What
matters for the scaffold is that the paragraph above, the code block, and the
diagram all rendered from one `.mdx` file, with the diagram sitting in a framed
`<Figure>` that scrolls rather than overflowing on a phone.
